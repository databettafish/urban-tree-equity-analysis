# Urban Tree Equity Analysis

## Project Overview
This project explores the relationship between urban tree cover and socioeconomic factors such as income and population demographics.

The goal is to investigate whether underserved communities have reduced access to green space, which can impact environmental quality and public health.

## Tools Used
- Python (Pandas, Matplotlib)
- Tableau
- GitHub

## Project Steps
1. Data collection
2. Data cleaning and preparation
3. Exploratory data analysis
4. Visualization (Python + Tableau)
5. Insights and conclusions

## Status
Project in progress – currently gathering datasets.
